# How to make a pop-up from scratch! for UMP.
## step 1
have your media ready. whats necessary:
- audio (optional)
- image (optional)
you **HAVE** to have one of them unless you want a useless popup on the app.
- text editor (nano / notepad should do the trick)

## step 2
create a directory. (eg. 'pops/ExampleDir') inside it you create a settings.ini with the following structure:

> \[Settings\]
>
> imageDir = *\[PATH TO YOUR IMAGE EG. image.png\]*\
> soundDir = *\[PATH TO YOUR IMAGE EG. image.png\]*\
> time = *\[INTEGER NUMBER\]*
